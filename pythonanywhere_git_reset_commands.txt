PYTHONANYWHERE GIT RESET COMMANDS
================================

Copy and paste these commands one by one into your PythonAnywhere SSH console:

1. Navigate to your project:
cd ~/AGTDesigner

2. Check current status:
git status

3. Fetch the latest changes:
git fetch origin

4. Reset to the stable commit (this will match your local revert):
git reset --hard origin/main

5. Verify the reset:
git log --oneline -1

6. Reload the web app:
touch /var/www/www_agtpricetags_com_wsgi.py

7. Test the app:
echo "✅ Deployment complete! Visit https://www.agtpricetags.com"

EXPECTED OUTPUT:
- You should see commit: "51e03e1 Add PythonAnywhere WSGI update script with latest optimizations and fixes"
- The app should load without "stuck on initializing"
- File uploads should work properly

TROUBLESHOOTING:
If you get any errors:
1. Check: git status
2. If there are conflicts: git reset --hard HEAD
3. Then run: git pull origin main
4. Finally: touch /var/www/www_agtpricetags_com_wsgi.py
