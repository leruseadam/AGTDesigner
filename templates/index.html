Help & Instructions
🚀 Quick Start (Current Flow)
  1. Upload product data: use Upload Excel (POSaBIT LOTs CSV) or Match JSON to merge database records.
  2. Choose your Store (top center) to load the right inventory.
  3. Filter by Vendor, Brand, Product Type, Lineage, Weight, DOH, High CBD.
  4. Select tags: check items on the left, or use Select All for a vendor/category. Drag to reorder in Selected.
  5. Pick a Template (Horizontal, Vertical, Mini, Double, Preroll, Inventory) and click Generate Tags.
  6. Export or manage data with Export Data, Data & Analytics, Edit DB, and Lineage Editor.
Batch Undo/Redo saves full selection snapshots Global filters stay while switching templates
🎯 Key Features
  • Smart Filters: stacked filter bar with live counts.
  • Batch Selection: vendor/category select-all, drag reorder.
  • Templates: multiple label layouts with color-coded controls.
  • Lineage Editor: edit lineage/colors directly from the center column.
  • Data Tools: Export, Analytics, Edit DB, JSON matching.
  • Undo/Redo: snapshot-based—restores whole batches, not single tags.
Tip: Keep the help overlay handy—press the “?” button anytime.
⌨️ Shortcuts & Controls
  • Undo / Redo: Ctrl/Cmd + Z / Ctrl/Cmd + Y (or buttons). Works on full selection snapshots.
  • Search: use the search bars above each list to filter instantly.
  • Drag & Drop: reorder selected tags to set print order.
  • Select All: vendor/category select toggles all items within that group.
  • Filters Persist: filters remain active when regenerating or switching templates.
🛠️ Troubleshooting
  • Upload stalled? Reclick Upload Excel and choose the CSV; refresh if TagManager isn’t ready.
  • Missing tags? Clear filters or reload current store from the store selector.
  • Undo/Redo not responding? Confirm the latest action saved—snapshot depth is 5.
  • Lineage colors off? Open Lineage Editor to re-map strains.
  • Layout tight? Use the template dropdown to switch to Inventory or Mini.
Still stuck? Try refresh; data and filters reload automatically when the store is selected.
